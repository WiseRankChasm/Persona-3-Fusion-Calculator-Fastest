## 🔮 How Fusion Works in Persona 3

Fusion in Persona 3 follows a strict arcana-based formula. Each Persona belongs to an arcana, and each arcana pair maps to a fixed result arcana.

| **Arcana A** | **Arcana B** | **Result Arcana** |
|---------------|---------------|--------------------|
| Fool | Magician | Hierophant |
| Priestess | Emperor | Empress |
| Lovers | Chariot | Strength |
| Hermit | Fortune | Star |
| Moon | Sun | Judgement |
| Devil | Tower | Hanged Man |

The calculator handles all 22 arcana combinations automatically — including the special fusion rules for ultimate Personas.

## 🧬 Skill Inheritance Rules

| **Rule** | **Description** | **Priority** |
|----------|-----------------|--------------|
| **Arcana Match** | Skills matching the result arcana inherit first | 🔥 High |
| **Parent Priority** | The first parent has higher inheritance weight | ⚡ Medium |
| **Duplicate Block** | Two parents with the same skill → only one inherits | ⚡ Medium |
| **Exclusive Skills** | Ultimate Personas keep unique skills | 🔥 High |
| **Null / Repel** | Defensive skills inherit last | 🌙 Low |

## 🧠 Fusion Strategy Tips

**Plan backwards.** Decide the target Persona first, then use reverse search to find every valid recipe.

**Use Skill Cards early.** In P3P and Reload, Skill Cards let you bypass inheritance rules entirely for key skills.

**Rank Social Links before fusing.** A maxed Social Link can push a fused Persona several levels higher.

**Fuse during a Fusion Alarm.** Reload's alarm system grants bonus skills and stat boosts — plan fusions around it.

**Keep a fusion log.** The calculator exports your recipes to a text file for later reference.
